## Overview

A sirocco is a hot, sand-laden wind that blows across the Mediterranean from the Sahara. It turns the sky sepia, dims the sun, and fills the air with particulate haze. The Sirocco program simulates these atmospheric disturbances electronically — a per-scanline brightness ripple creates heat shimmer, sparse pseudo-random particles add sandstorm texture, a colour temperature shift warms the palette, and a contrast push makes the image feel bleached and sun-baked.

The program chains four independent processing stages — brightness ripple, sand particle overlay, contrast boost, and colour temperature shift — each with its own toggle switch. The ripple uses an 8-entry quarter-wave sine lookup table that scrolls through vertical position with a frame-rate phase accumulator, producing undulating brightness bands that drift down the screen. The sand particles are generated by a 16-bit LFSR hashed with horizontal and vertical position — when the hash value falls below the density threshold, a bright dot appears.

At conservative settings Sirocco produces a subtle atmospheric warmth and gentle shimmer. At extreme settings it buries the image in noise and ripple, reducing visibility like a real sandstorm. The wet/dry mix fader allows these effects to be blended gently with the original signal.

## Background

### What Is Atmospheric Shimmer?

When hot air rises from sun-baked ground, it creates turbulent cells of varying refractive index. Light passing through these cells is bent unpredictably, causing objects to appear to wiggle and shift — the "heat shimmer" effect visible over highways, runways, and desert sand. Sirocco simulates this by modulating brightness along the vertical axis using a slow sine wave, creating undulating bands of lighter and darker tones that drift with the phase accumulator.

### What Is LFSR Noise?

A **Linear Feedback Shift Register** (LFSR) is a shift register whose input bit is a linear function (XOR) of its previous state. The output sequence appears random but is deterministic and repeatable. Sirocco uses a 16-bit LFSR as a noise source, XOR-hashing it with the horizontal and vertical pixel positions to produce a spatially distributed pseudo-random pattern. When the hash falls below a threshold, a bright "sand particle" is drawn at that pixel location.

### What Is Colour Temperature?

Colour temperature describes how warm or cool light appears. The sun at midday is approximately 5500K (neutral white), but at sunset it drops to ~3000K (warm amber). Sirocco shifts colour temperature by adding to the V (red-difference) channel and subtracting from the U (blue-difference) channel. More V and less U shifts the image toward warm reds and oranges — the characteristic palette of a desert sandstorm viewed through atmospheric haze.

### What Is Contrast Enhancement?

Pushing Y values away from the midpoint (512 in 10-bit) — brightening bright pixels and darkening dark pixels — increases the overall contrast of the image. Sirocco's high-contrast toggle adds `(Y-512)/4` back to Y, a gentle boost that makes the image feel more vivid and sun-bleached. This simulates the way intense desert light washes out shadow detail while burning highlights.

### What Is a Quarter-Wave Sine LUT?

A full sine wave repeats every 360°, but its shape is symmetrical — the first 90° (0→1) mirrors the next three quadrants. Sirocco stores only the first quadrant (8 entries covering 0° to 90°) and reconstructs the full wave via mirroring and sign inversion. This reduces the lookup table to just 8 entries while producing a smooth 32-step sine wave. The values are scaled to 7-bit unsigned (0–125), then adjusted by the ripple amplitude parameter.

## Signal Flow

```
Input Video (YUV 4:4:4)
│
├── Stage 0: Input + Counters ──────────────────────────────────
│   ├─ Register input Y, U, V
│   ├─ Horizontal / vertical position counters
│   └─ Phase accumulator (increments per-frame from ripple_spd>>4)
│
├── Stage 1: Sine LUT + Sand Hash ─────────────────────────────
│   ├─ Quarter-wave sine lookup: index = (v_count[4:0] + phase[4:0])
│   │   ├─ 8-entry LUT with quadrant mirroring
│   │   └─ Output: sine_val (7-bit), sine_sign
│   └─ Sand hash = h_count XOR lfsr[11:0] XOR rotated v_count
│
├── Stage 2: Sand Hit Test + Ripple Scaling ────────────────────
│   ├─ Sand hit: hash[11:4] < sand_density[9:2]
│   └─ Ripple scale: 4 tiers based on ripple_amt
│       ├─ amt < 256: sine >> 3
│       ├─ amt < 512: sine >> 2
│       ├─ amt < 768: sine >> 1
│       └─ else:      sine × 1
│
├── Stage 3: Apply Ripple + Sand ───────────────────────────────
│   ├─ Brightness ripple: sat_add/sub Y by scaled sine
│   └─ Sand particles: +sand_bright>>1 to Y, +8 to V
│
├── Stage 4: Contrast + Warmth ─────────────────────────────────
│   ├─ Contrast: (Y-512)>>2 added/subtracted (hi_contrast toggle)
│   └─ Warmth: +warmth>>3 to V, -(warmth>>3)>>1 from U
│
├── Stage 5: Output Register ──────────────────────────────────
│   └─ Pipeline register
│
├── Stages 6–9: Interpolator Mix ──────────────────────────────
│   └─ wet/dry crossfade via mix_amount
│
├── Sync Signals ──────────────────────────────────────────────
│   └─ Pass-through with matched delay (10 clocks)
│
└── Bypass ────────────────────────────────────────────────────
    └─ Select original or processed signal
```

The ripple and sand systems run independently — the sine LUT produces a smooth vertical brightness wave, while the LFSR produces spatially scattered bright dots. Both modify the Y channel but in completely different spatial patterns: the ripple creates horizontal bands that shift vertically over time, while the sand creates sparse individual pixels that appear randomly across the frame. The colour temperature shift and contrast boost operate downstream of both, modifying all pixels regardless of whether they were hit by sand or ripple. The final interpolator stage crossfades between the original (dry) and processed (wet) signals, so the mix fader controls the overall intensity of all effects simultaneously.

## Parameter Reference

<img src={sirocco_control_panel} alt="Videomancer front panel with Sirocco loaded"/>
*Videomancer's front panel with Sirocco active. Knobs 1–6 (top two rows of left cluster), Toggle switches 7–11 (bottom row of left cluster), Fader 12 (right side).*

### Rotary Potentiometers (Knobs 1–6)

#### Knob 1 — Intensity
| Property | Value |
|----------|-------|
| Range | 0.0% – 100.0% |
| Default | 50.0% |
| Suffix | % |

Controls the amplitude of the vertical brightness ripple. This maps to the VHDL `s_ripple_amt` signal. The sine wave amplitude is scaled in four tiers: below 25% the ripple is very gentle (sine >> 3, maximum ~15 levels), from 25%–50% it doubles (sine >> 2), from 50%–75% it doubles again (sine >> 1), and above 75% the full sine amplitude applies (~125 levels peak-to-peak). The ripple creates slowly undulating horizontal bands of brighter and darker tones across the image.

---

#### Knob 2 — Turbulen
| Property | Value |
|----------|-------|
| Range | 0.0% – 100.0% |
| Default | 50.0% |
| Suffix | % |

Controls the speed of the ripple phase accumulator. This maps to `s_ripple_spd`. At 0% the ripple bands are static. As you increase the control, the phase accumulator increments faster per frame (top 6 bits of the register, shifted right by 4), causing the sine wave pattern to scroll vertically through the image. Higher values create faster heat shimmer animation. The effect is most visible when Shimmer toggle is enabled.

---

#### Knob 3 — Haze Amt
| Property | Value |
|----------|-------|
| Range | 0.0% – 100.0% |
| Default | 37.5% |
| Suffix | % |

Controls the density of sand particles. This maps to `s_sand_density`. The LFSR hash is compared against `density >> 2` — higher density values cause more hash values to pass the threshold, producing more frequent sand dots across the frame. At 0% no sand particles appear. At 100% the frame fills with bright speckle. The sand effect requires the Storm toggle (Switch 7) to be enabled.

---

#### Knob 4 — Shimmer
| Property | Value |
|----------|-------|
| Range | 0.0% – 100.0% |
| Default | 37.5% |
| Suffix | % |

Controls the brightness of individual sand particles. This maps to `s_sand_bright`. Each sand hit adds `sand_bright >> 1` to the Y channel and a fixed +8 to V (adding a warm tint to each particle). At low values the particles are subtle bright specks. At high values they are intense white-hot dots that punch through the image. The effect is most visible against darker backgrounds.

---

#### Knob 5 — Wind Dir
| Property | Value |
|----------|-------|
| Range | 0° – 360° |
| Default | 90° |
| Suffix | ° |

Controls the colour temperature shift amount. Despite the TOML label "Wind Dir," this maps to the VHDL `s_warmth` signal. The warmth shift adds `warmth >> 3` to V and subtracts `(warmth >> 3) >> 1` from U, pushing the entire image toward warm amber-red tones. At 0% no colour shift occurs. At maximum the image takes on a deep sepia/amber cast typical of a sandstorm viewed through atmospheric haze. Requires the Direction toggle (Switch 9, mapped to `s_color_en`) to be enabled.

---

#### Knob 6 — Warmth
| Property | Value |
|----------|-------|
| Range | 0.0% – 100.0% |
| Default | 50.0% |
| Suffix | % |

Controls the Y contrast boost intensity. Despite the TOML label "Warmth," this maps to the VHDL `s_contrast` register. Note: the VHDL contrast boost is controlled by the `s_hi_contrast` toggle (Switch 10, mapped to "Animate" in TOML) rather than this register value — when the toggle is on, the boost applies `(Y-512)/4` unconditionally. This parameter is reserved for future use in the current VHDL implementation.

---

### Toggle Switches (Switches 7–11)

| Switch | Off | On |
|--------|-----|-----|
| **7 — Storm** | Sand | Dust |
| **8 — Shimmer** | Off | On |
| **9 — Direction** | Horiz | Vert |
| **10 — Animate** | Off | On |
| **11 — Bypass** | Off | On |

The four effect toggles (Switches 7–10) independently enable or disable the four processing stages: sand particles, brightness ripple, colour temperature shift, and contrast boost. Each can be turned on or off without affecting the others. Switch 11 bypasses all processing entirely. The TOML labels don't directly match the VHDL signal names: Storm → `s_sand_en`, Shimmer → `s_ripple_en`, Direction → `s_color_en`, Animate → `s_hi_contrast`.

---

### Linear Potentiometer (Fader 12)

#### Fader 12 — Mix
| Property | Value |
|----------|-------|
| Range | 0.0% – 100.0% |
| Default | 100.0% |
| Suffix | % |

Controls the wet/dry mix crossfade via three `interpolator_u` instances. At 0% (register 0) the output is the original unprocessed signal. At 100% (register 1023) the output is fully processed. Intermediate values blend the processed signal with the original, allowing subtle atmospheric effects to be introduced without overwhelming the source image.

## Guided Exercises

These exercises build from individual effects to the full sandstorm simulation. Each exercise isolates one aspect of the processing chain before combining them.

### Exercise 1: Heat Shimmer Ripple

<img src={sirocco_exercise1_result} alt="Heat Shimmer Ripple result"/>
*Heat Shimmer Ripple — simulated result across source images.*
**Source**: Footage of a static scene (landscape, architectural shot) where the ripple bands will be clearly visible against straight horizontal lines.

**Objective**: Learn how the sine ripple creates atmospheric shimmer by modulating brightness vertically.

1. **Isolate ripple**: Enable Shimmer (Switch 8 On), disable Storm (Switch 7 low), disable Direction (Switch 9 low), disable Animate (Switch 10 Off).
2. **Set moderate amplitude**: Turn Intensity to about 50%.
3. **Start animation**: Increase Turbulence from 0% slowly. Watch the horizontal brightness bands begin to scroll vertically.
4. **Adjust speed**: Higher Turbulence values speed up the shimmer. Find a natural-looking rate around 30–40%.
5. **Full amplitude**: Push Intensity to 100% to see the maximum ripple depth (~125 levels peak-to-peak).
6. **Mix**: Use the Mix fader to dial back the effect to a subtle level (~40%).

**Key concepts**: Sine LUT indexed by vertical position + phase accumulator, quadrant mirroring reproduces full sine from 8 entries, four amplitude tiers from register value

---

### Exercise 2: Sand Particle Storm

<img src={sirocco_exercise2_result} alt="Sand Particle Storm result"/>
*Sand Particle Storm — simulated result across source images.*
**Source**: Dark or mid-toned footage where bright particles will stand out clearly.

**Objective**: Explore the LFSR-based sand particle system and understand density vs. brightness.

1. **Isolate sand**: Enable Storm (Switch 7 high), disable Shimmer (Switch 8 Off), disable Direction (Switch 9 low).
2. **Start sparse**: Set Haze Amt to about 20%. Bright specks should appear scattered across the frame.
3. **Increase density**: Push Haze Amt toward 60%. The frame fills with more particles.
4. **Adjust brightness**: Sweep Shimmer (pot 4) from 0% to 100%. Particles go from subtle flecks to intense white-hot dots.
5. **Notice V tint**: Each sand particle adds +8 to V — in dense fields this creates a warm reddish tint to the particle area.
6. **Combine with warmth**: Enable Direction (Switch 9 high) and set Wind Dir to ~60% for sepia tone.

**Key concepts**: LFSR XOR hash creates spatially pseudo-random particle placement, density threshold controls hit rate, sand_bright controls per-particle Y addition, fixed +8 V adds warm tint

---

### Exercise 3: Full Desert Sandstorm

<img src={sirocco_exercise3_result} alt="Full Desert Sandstorm result"/>
*Full Desert Sandstorm — simulated result across source images.*
**Source**: Any footage — the effect works on all content, but outdoor landscapes and portraits are particularly evocative.

**Objective**: Combine all four processing stages to create a complete sandstorm simulation.

1. **Enable everything**: Storm high, Shimmer On, Direction high, Animate On.
2. **Set base levels**: Intensity ~50%, Turbulence ~30%, Haze Amt ~35%, Shimmer ~50%.
3. **Warm the palette**: Wind Dir ~70%. The entire image shifts toward amber.
4. **Contrast boost**: The Animate toggle pushes Y values away from mid-grey, creating a sun-bleached look.
5. **Mix for realism**: Start with Mix at 100%, then dial back to ~60% for a more natural atmospheric effect.
6. **Sweep**: Slowly animate Intensity up and down to simulate gusting wind. Increase Haze Amt for a heavier storm.

**Key concepts**: Four independent effect layers (ripple, sand, warmth, contrast) combine to create atmospheric simulation, mix fader allows subtle blending, all effects are independently toggleable

## Tips

- **Start with one effect**: Enable ripple, sand, warmth, or contrast individually before combining. Each has its own character and it's easier to understand the interaction when you build up layer by layer.
- **Mix is your master intensity**: Rather than reducing each individual parameter, use the Mix fader to dial back the entire sandstorm effect proportionally. This maintains the relative balance between effects.
- **Turbulence at 0% for still photography**: Setting Turbulence to 0% freezes the ripple bands in place, creating static horizontal brightness banding useful for texture overlays and still image processing.
- **Sand density vs. brightness tradeoff**: Dense, dim particles (high Haze Amt, low Shimmer) create a hazy dust cloud. Sparse, bright particles (low Haze Amt, high Shimmer) create occasional intense flashes — more like embers or fireflies than sand.
- **Warmth stacks with sand V tint**: The per-particle V+8 tint adds to the global warmth shift, so sand-heavy areas appear even warmer than the background. This creates a natural depth effect where particulate-rich regions look more sun-baked.
- **Feedback for storms**: Route the output back to the input to create compounding sand and ripple. Each pass adds more particles and deepens the ripple, simulating an intensifying storm.
- **Contrast for daylight feel**: The high-contrast toggle makes images feel like harsh midday desert sun. Combine with high warmth for a convincing "noon in the Sahara" look.

## Glossary

| Term | Definition |
|------|------------|
| **BT.601** | ITU-R Recommendation BT.601; the colour encoding standard used for standard-definition video, defining YUV coefficients used throughout Videomancer. |
| **Colour Temperature** | A measure of how warm (amber) or cool (blue) light appears, expressed in Kelvin. Sirocco shifts colour temperature by modifying U and V channels. |
| **FPGA** | Field-Programmable Gate Array; a reconfigurable integrated circuit that executes the video processing pipeline. |
| **Interpolator** | A hardware module that linearly crossfades between two input values based on a third value (the mix control). |
| **LFSR** | Linear Feedback Shift Register; a deterministic pseudo-random number generator used for sand particle placement. |
| **Luma** | The brightness component (Y) of a YUV video signal, representing perceived lightness. |
| **Phase Accumulator** | A counter that increments by a controllable amount each frame, used to animate the sine wave ripple over time. |
| **Pipeline** | A series of sequential processing stages where each stage's output feeds the next stage's input on each clock cycle. |
| **Quarter-Wave LUT** | A lookup table storing only 0°–90° of a sine wave, reconstructing the full wave via symmetry and sign inversion. |
| **Saturating Arithmetic** | Addition or subtraction that clamps the result to the valid range (0–1023) instead of wrapping around on overflow or underflow. |
| **YUV** | A colour encoding that separates luminance (Y) from chrominance (U, V), used throughout the Videomancer video pipeline. |
