## Overview

Amphora recreates the visual language of Classical Greek painted pottery, transforming input video into images resembling Attic black-figure and red-figure ceramic vase painting. The program uses binary luminance thresholding to split the image into figure and ground regions, then fills each region with authentic pottery surface colours — terra-cotta (fired clay), black glaze, or white slip. Horizontal and vertical gradient-based edge detection overlays detail lines resembling the incised or painted linear detail found on original pottery. A Greek key meander border can be applied at the frame edges. A specular gloss highlight adds surface sheen via LFSR-based noise.

The name *Amphora* references the two-handled vessel that was the most celebrated form in Attic pottery, produced in Athens from the 7th through 4th centuries BCE. The program specifically references two masterworks: the Euphronios Krater (c. 515 BCE, depicting the death of Sarpedon) and Exekias' Ajax and Achilles amphora (c. 540 BCE, Vatican Museums), which represent the pinnacle of red-figure and black-figure techniques respectively.

At conservative settings — moderate threshold with detail lines enabled and thin meander border — the program produces a convincing ceramic rendering with clear figure-ground separation. At extreme settings — radical threshold positions, wide meander border, heavy gloss — the image becomes a stark graphic abstraction in pottery colours.

## Background

### What Are Black-Figure and Red-Figure Pottery?

**Black-figure** pottery (c. 620–480 BCE) was the earlier technique: figures were painted in black slip (refined clay) on the natural red-orange terra-cotta body of the vessel, then detail was incised through the slip with a stylus to reveal the clay beneath. The result is dark silhouettes with fine linear internal detail against a warm clay background.

**Red-figure** pottery (c. 530–300 BCE) inverted the technique: the background was painted black and the figures were left in the natural clay colour. Detail lines were painted in dilute glaze rather than incised. This reversal allowed greater freedom for internal detail — painters could use a brush rather than a stylus, enabling more naturalistic rendering of anatomy and drapery.

In this program, the Technique toggle switches between these two modes by swapping which colour fills figures and which fills the ground.

### What Is the Greek Key Meander?

The **meander** (Greek key) is one of the most recognizable decorative motifs in Classical Greek art. It consists of a continuous line that folds back on itself in a repeating pattern of right-angled steps. On pottery, meander borders typically frame the main figurative scene, running along the top and bottom or around the neck and foot of the vessel. The pattern symbolised infinity and the eternal flow of life.

In Amphora, the meander is generated by modular coordinate arithmetic — the horizontal and vertical pixel positions modulo a 16-pixel unit cycle determine whether each border pixel is filled with black or terra-cotta, creating the alternating stepped pattern.

### What Is Terra-Cotta?

**Terra-cotta** (Italian: "baked earth") is the red-orange clay body of fired pottery. The distinctive warm colour comes from iron oxide in the clay, which turns various shades of orange, red, and brown depending on the kiln temperature and atmosphere. Attic potters used particularly fine clay from the Kerameikos district of Athens, which fires to a rich orange-red.

## Signal Flow

```
Input Video (YUV 4:4:4 30-bit)
│
├── Y Channel ──────────────────────────────────────────────────────
│   │
│   ├─ 1.  Binary threshold          (Y < threshold → figure, else ground)
│   │       + line buffer write/read  (store Y for vertical edge detect)
│   ├─ 2.  Edge detection             (|curr-prev| horizontal +
│   │                                  |curr-above| vertical gradient,
│   │                                  sum vs sensitivity threshold)
│   ├─ 3.  Figure/ground fill         (black-fig or red-fig mode:
│   │       + edge overlay              figure=black/terra, ground=terra/black
│   │                                  + detail line overlay on edges)
│   ├─ 4.  Meander border            (modular 16-px Greek key pattern
│   │                                  at frame edges, width from pot)
│   └─ 5.  Gloss highlight           (additive LFSR noise × gloss pot)
│
├── Sync Signals ───────────────────────────────────────────────────
│   └─ 9-clock delay pipeline         (align with processing depth)
│
├── Interpolator (4 clocks per channel) ────────────────────────────
│   └─ Mix = lerp(input_delayed, processed, mix_amount)
│
└── Output ─────────────────────────────────────────────────────────
    └─ Y/U/V from interpolator mix
```

The line buffer stores one full scanline of 10-bit Y data (2048 entries) for vertical edge detection. On each pixel clock, the current Y value is written and the previous scanline's Y at the same position is read simultaneously. The horizontal gradient uses the previous pixel's Y value (one register delay). Both gradients are summed and compared against a sensitivity threshold derived from the Line Sens pot.

The terra-cotta hue can be adjusted via the Terra Hue pot, which applies an offset to the preset U and V values of the terra-cotta colour constant. This allows shifting the pottery surface from orange-red through brown to a cooler clay tone. The White Ground toggle replaces the terra-cotta ground/figure colour with a white slip colour, simulating the white-ground lekythos technique.

## Parameter Reference

<img src={amphora_control_panel} alt="Videomancer front panel with Amphora loaded"/>
*Videomancer's front panel with Amphora active. Knobs 1–6 (top two rows of left cluster), Toggle switches 7–11 (bottom row of left cluster), Fader 12 (right side).*

### Rotary Potentiometers (Knobs 1–6)

#### Knob 1 — Threshold
| Property | Value |
|----------|-------|
| Range | 0% – 100% |
| Default | 50% |
| Suffix | % |

Controls the luminance threshold level that separates figure from ground regions. Pixels with Y values below the threshold are classified as "figure" and pixels at or above are classified as "ground." At low threshold, almost everything is ground — only the darkest shadows register as figure. At high threshold, almost everything is figure — only the brightest highlights remain as ground. The optimal setting depends on the source material: well-exposed portraits typically work best at mid-range values around 50%.

---

#### Knob 2 — Line Weight
| Property | Value |
|----------|-------|
| Range | 0% – 100% |
| Default | 38% |
| Suffix | % |

Controls the thickness of the edge detail lines. Higher values make the edge detection more aggressive, classifying wider gradient zones as edge pixels. At minimum, only the sharpest transitions produce visible lines. At maximum, even gentle gradients produce broad strokes. This interacts with Line Sens — weight controls how much gradient is enough, while sensitivity controls how finely the gradient is measured.

---

#### Knob 3 — Line Sens
| Property | Value |
|----------|-------|
| Range | 0% – 100% |
| Default | 50% |
| Suffix | % |

Controls the sensitivity of the edge detector. Higher values lower the detection threshold, making the system responsive to subtler gradients and producing more detail lines. At minimum, only very strong edges (high-contrast boundaries) produce lines. At maximum, fine texture detail throughout the image becomes visible as an overlay of incised-looking lines.

---

#### Knob 4 — Border W
| Property | Value |
|----------|-------|
| Range | 0% – 100% |
| Default | 0% |
| Suffix | % |

Controls the width of the meander border at the frame edges in pixels. At minimum, the border is invisible (or only 4 pixels, the minimum unit). At maximum, the border extends far into the frame, consuming significant image area with the Greek key pattern. The border is only visible when the Meander toggle is enabled.

---

#### Knob 5 — Terra Hue
| Property | Value |
|----------|-------|
| Range | 0° – 360° |
| Default | 0° |
| Suffix | ° |

Selects the hue of the terra-cotta pottery surface. The default centre position produces the standard Attic orange-red. Rotating away from centre shifts the hue through warmer (more orange/gold) or cooler (more brown/sienna) tones by offsetting the U and V components of the terra-cotta colour constant. This is a polar 360° control.

---

#### Knob 6 — Gloss
| Property | Value |
|----------|-------|
| Range | 0% – 100% |
| Default | 50% |
| Suffix | % |

Controls the intensity of the specular gloss highlight. At 0%, the surface is completely matte — no specular sheen. At higher values, an additive noise pattern (from a 16-bit LFSR) brightens random pixels, simulating the subtle sparkle of glazed ceramic surfaces under lighting. At maximum, the gloss effect is very pronounced, adding significant brightness variation.

---

### Toggle Switches (Switches 7–11)

| Switch | Off | On |
|--------|-----|-----|
| **7 — Technique** | Black-Fig | Red-Fig |
| **8 — Detail Line** | On | Off |
| **9 — Meander** | Off | On |
| **10 — White Grnd** | Standard | White |
| **11 — Bypass** | Off | On |

Toggle 7 is a **binary technique selector** (Black-Figure vs Red-Figure). Toggles 8, 9, and 10 are **independent binary controls**: Detail Line enables/disables edge overlay, Meander enables/disables the Greek key border, and White Ground substitutes white slip for terra-cotta in the ground colour.

---

### Linear Potentiometer (Fader 12)

#### Fader 12 — Mix
| Property | Value |
|----------|-------|
| Range | 0% – 100% |
| Default | 100% |
| Suffix | % |

Wet/dry crossfade between the original input video (delayed to match the 9-clock processing pipeline plus 4-clock interpolator) and the pottery-rendered output. At 0%, pure unprocessed input. At 100%, fully processed pottery rendering.

## Guided Exercises

These exercises progress from basic black-figure rendering through red-figure with edge detail to complete compositions with meander borders and surface gloss.

### Exercise 1: Classic Black-Figure Rendering

<img src={amphora_exercise1_result} alt="Classic Black-Figure Rendering result"/>
*Classic Black-Figure Rendering — simulated result across source images.*
**Source**: Portrait or figure photography with clear subject/background separation.

**Objective**: Understand how the luminance threshold separates figure from ground and how the Black-Figure technique renders the result.

1. **Set Black-Figure**: Toggle Technique to Black-Fig. Detail Line Off, Meander Off, White Grnd Standard.
2. **Default threshold**: Set Threshold to ~50%. The image splits into black figures on terra-cotta ground.
3. **Observe separation**: Dark areas of the image become black glaze, bright areas become terra-cotta clay. The boundary between them is the threshold line.
4. **Lower threshold**: Drop Threshold to ~25%. More of the image becomes terra-cotta ground — only the darkest shadows remain as black figures.
5. **Raise threshold**: Push Threshold to ~75%. More of the image becomes black figures — only the brightest highlights remain as terra-cotta.
6. **Adjust terra hue**: Rotate Terra Hue to shift the clay colour from warm orange to cooler brown.
7. **Full mix**: Set Mix to 100%.

**Key concepts**: Binary luminance thresholding, figure/ground separation, Black-Figure technique, terra-cotta hue adjustment

### Exercise 2: Red-Figure with Detail Lines

<img src={amphora_exercise2_result} alt="Red-Figure with Detail Lines result"/>
*Red-Figure with Detail Lines — simulated result across source images.*
**Source**: Subject with fine detail — textured fabric, hair, or architectural surfaces.

**Objective**: Explore Red-Figure mode with edge-detected detail lines, simulating the painted-line technique of red-figure pottery.

1. **Set Red-Figure**: Toggle Technique to Red-Fig. Detail Line On, Meander Off.
2. **Moderate threshold**: Threshold at ~45%. Terra-cotta figures on black ground.
3. **Enable detail**: Increase Line Sens to ~60%. Edge lines begin appearing as dark strokes over the figure regions.
4. **Adjust weight**: Set Line Weight to ~40%. The lines thicken, creating more prominent detail strokes.
5. **Fine sensitivity**: Increase Line Sens to ~80%. Subtle texture detail becomes visible as fine incised-looking lines.
6. **Add gloss**: Set Gloss to ~25%. A subtle specular sparkle appears on the surface, simulating glazed ceramic.
7. **Compare modes**: Toggle between Black-Fig and Red-Fig to see how the same edge detail looks in each technique.

**Key concepts**: Red-Figure technique, horizontal and vertical gradient edge detection, line weight vs sensitivity, detail line colour (dilute glaze)

### Exercise 3: Complete Amphora with Meander Border

<img src={amphora_exercise3_result} alt="Complete Amphora with Meander Border result"/>
*Complete Amphora with Meander Border — simulated result across source images.*
**Source**: Any video source — the full composition with border works with any content.

**Objective**: Create a complete pottery rendering with meander border, detail lines, and gloss for the most authentic Classical Greek ceramic look.

1. **Full setup**: Red-Fig, Detail Line On, Meander On, White Grnd Standard.
2. **Border width**: Set Border W to ~30%. A Greek key pattern frames the image.
3. **Moderate detail**: Threshold ~50%, Line Weight ~30%, Line Sens ~60%.
4. **Add terra hue warmth**: Terra Hue to ~170° for a warm orange-red clay.
5. **Moderate gloss**: Gloss to ~20%. Subtle surface sheen.
6. **Try White Ground**: Toggle White Grnd to White. The ground colour changes to white slip — a very different aesthetic.
7. **Wide border**: Push Border W to ~60%. The meander border dominates, framing a smaller central image area.

**Key concepts**: Meander border generation, modular coordinate pattern, white-ground technique, full composition assembly

## Tips

- **Threshold is the primary creative control**: The threshold level determines the figure/ground split point and is the most impactful parameter. Adjust it first, then refine with other controls.
- **Detail lines add authenticity**: Real Attic pottery has extensive internal line work — drapery folds, muscle definition, facial features. Enable detail lines for the most authentic look.
- **Red-Figure is more versatile**: Red-Figure mode preserves more visual detail because the warm terra-cotta figures show the line work more clearly than black silhouettes.
- **Meander border frames the composition**: Even a thin meander border adds significant visual authority to the pottery rendering. Use moderate widths (15-30%) for the most authentic proportions.
- **Terra Hue for different clays**: Different pottery traditions used different clays — shift toward orange for Attic, toward brown for Corinthian, toward yellow for Boeotian.
- **Gloss simulates glaze**: Real pottery has a glassy surface sheen from the silica content of the slip. A subtle gloss setting (10-20%) adds this quality without overwhelming the image.
- **White Ground for lekythos style**: The White Ground mode simulates the white-ground lekythos technique used for funerary vessels — a distinctive and elegant variation.
- **Feedback loops create nested threshold effects**: Routing the output back creates recursive thresholding that quickly converges to a pure two-colour image.

## Glossary

| Term | Definition |
|------|------------|
| **Attic** | Relating to Attica, the region around Athens; Attic pottery is the scholarly term for the black-figure and red-figure ceramics produced in Athens from the 7th–4th centuries BCE. |
| **Black-Figure** | A pottery decoration technique (c. 620–480 BCE) where figures are painted in black glaze on the natural red clay body, with detail incised through the slip. |
| **Edge Detection** | A signal-processing operation that identifies boundaries in an image by measuring the gradient (rate of change) between adjacent pixels. |
| **Gradient** | The difference in value between neighbouring pixels; a large gradient indicates a sharp edge, a small gradient indicates a smooth region. |
| **LFSR (Linear Feedback Shift Register)** | A shift register whose input bit is computed from a linear function of its previous state, producing a deterministic pseudo-random bit sequence used here for gloss noise. |
| **Line Buffer** | A BRAM-based memory that stores one full scanline of pixel data, allowing the current line to be compared with the previous line for vertical edge detection. |
| **Luminance (Luma)** | The brightness component (Y channel) of a YUV video signal. |
| **Meander (Greek Key)** | A repeating geometric border pattern of right-angled folds, ubiquitous in Classical Greek decorative art and generated here by modular coordinate arithmetic. |
| **Red-Figure** | A pottery technique (c. 530–300 BCE) that reverses black-figure: the background is painted black and figures are left in natural clay, with details painted in dilute glaze. |
| **Terra-Cotta** | The natural red-orange colour of fired iron-rich clay; the base body colour of Greek pottery and the primary surface tint in Amphora. |
| **Threshold** | A fixed value against which each pixel's luminance is compared to classify it as figure or ground. |
| **White Ground (Lekythos)** | A technique using a white clay slip on the vessel surface instead of the natural red clay, associated with funerary lekythos vessels. |
| **YUV** | A colour encoding separating brightness (Y) from colour (U, V); Videomancer's native 30-bit processing colour space. |
