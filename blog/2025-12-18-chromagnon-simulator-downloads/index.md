Hi everyone! As promised, I've made my Chromagnon Simulator available for download as portable applications for Windows, macOS, and Linux.  This was a tool created for design reference during development of the hardware, so it is not very polished or useful beyond getting a preview of the instrument's functionality -- which I hope you will enjoy!  The Windows version should run fine, but the MacOS and Linux versions are largely untested.  If you have trouble running them, find access to a Windows machine to play with the app.  If I hear about any fixes necessary to get them running on your platform, I'll post about it here.  I'll share some more news about Chromagnon and Videomancer soon.
